# Haine de test (doar pentru preview)

Pozele din acest folder sunt folosite **doar ca să vedem magazinul plin**. Nu sunt produse de vânzare și se șterg înainte de lansare, odată cu intrările `sample: true` din `js/products.js`.

Surse:
- Tricouri, hanorace, polo: imaginile demo din [saleor/saleor](https://github.com/saleor/saleor) (BSD-3-Clause) și [solidusio/solidus](https://github.com/solidusio/solidus) (BSD-3-Clause).
- Rochii, fuste, cămăși, blugi, pantaloni, geci: [alexeygrigorev/clothing-dataset-small](https://github.com/alexeygrigorev/clothing-dataset-small) (CC0).

Fundalul a fost scos automat (rembg). Prețurile, mărimile și detaliile sunt inventate.
